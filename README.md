# Real-Time National Land Acquisition & Management System

**Smart India Hackathon** | **Problem Statement:** PS26016
**Organization:** Ministry of Rural Development (DoLR)

## 📌 Project Overview
A unified, web-based platform that digitizes the complete land acquisition lifecycle. This system provides standardized workflows, GIS-enabled geo-tagging, and real-time tracking from project proposal to final land possession to enhance transparency and data-driven governance.

## 🏗️ Repository Structure
* `/frontend` - Next.js/React UI, mobile-responsive screens, and GIS map integrations.
* `/backend` - Node.js/Python API, role-based access control (RBAC), and workflow automation.
* `/database` - SQL schemas and spatial database configurations.
* `/docs` - SIH presentation (PPT), architecture diagrams, and API documentation.
* `/design` - UI/UX wireframes and Figma assets.
